How to Use This Tool

This tool generates personalized MaaS360 renewal and upsell emails using real account data.

Step 1 — Fill in Account Details

Complete as many fields as possible. Required fields (*) must be filled. Optional fields that are left blank appear as [PLACEHOLDER] in the output for you to complete before sending.

Step 2 — Select Email Type
  • Upsell / Upgrade — Edition upgrade recommendation based on device scale and ACV
  • Renewal — Renewal review with license true-up and upgrade options
  • Security Risk — Mobile security posture review positioning Secure Browser and MTD
  • Check-In / QBR — Proactive touchpoint ahead of renewal
  • Recommended Options — Combined renewal + upgrade view with side-by-side options
Step 3 — Generate & Copy

Click Generate Personalized Email. Review the output, then click Copy Email to paste into Outlook or Gmail. Business context and seller notes are never copied verbatim — they inform the recommendation language only.

Pro Tip: Save this file to your desktop and open it in Chrome or Edge. It works fully offline — no data is sent anywhere.
